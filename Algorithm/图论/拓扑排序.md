# 拓扑排序

拓扑排序把有向无环图（DAG）的顶点排成线性序列，使每条边 `u -> v` 中 `u` 都出现在 `v` 之前。它用于构建依赖、课程先修关系、任务调度和编译顺序。图存在有向环时不存在拓扑序列。

**示例环境：C# 14、.NET 10。** 文档给出 Kahn 入度算法，并补充 DFS 三色标记法。

## 1. Kahn 算法

先统计每个顶点的入度，把入度为 0 的顶点放入队列；取出后删除其出边，使邻接顶点入度减 1，降为 0 时入队。若最终输出顶点数小于 `V`，剩余顶点位于环中。

时间复杂度 `O(V + E)`，空间复杂度 `O(V + E)`。使用 `PriorityQueue<int,int>` 可在多个合法顶点中始终选择编号最小者，得到字典序最小拓扑序，复杂度变为 `O((V + E) log V)`。

```csharp
public static class TopologicalSort
{
    public static int[] Kahn(IReadOnlyList<IReadOnlyList<int>> graph)
    {
        int n = graph.Count;
        int[] indegree = new int[n];
        for (int u = 0; u < n; u++)
            foreach (int v in graph[u])
            {
                if ((uint)v >= (uint)n) throw new ArgumentOutOfRangeException(nameof(graph));
                indegree[v]++;
            }

        var queue = new Queue<int>();
        for (int i = 0; i < n; i++) if (indegree[i] == 0) queue.Enqueue(i);
        int[] order = new int[n];
        int count = 0;
        while (queue.TryDequeue(out int u))
        {
            order[count++] = u;
            foreach (int v in graph[u])
                if (--indegree[v] == 0) queue.Enqueue(v);
        }
        if (count != n) throw new InvalidOperationException("图包含有向环，无法拓扑排序");
        return order;
    }

    public static int[] LexicographicallySmallest(IReadOnlyList<IReadOnlyList<int>> graph)
    {
        int n = graph.Count; int[] degree = new int[n];
        for (int u = 0; u < n; u++)
            foreach (int v in graph[u])
            {
                if ((uint)v >= (uint)n)
                    throw new ArgumentOutOfRangeException(nameof(graph));
                degree[v]++;
            }
        var q = new PriorityQueue<int, int>();
        for (int i = 0; i < n; i++) if (degree[i] == 0) q.Enqueue(i, i);
        var order = new List<int>(n);
        while (q.TryDequeue(out int u, out _))
        {
            order.Add(u);
            foreach (int v in graph[u])
                if (--degree[v] == 0) q.Enqueue(v, v);
        }
        return order.Count == n ? order.ToArray() : throw new InvalidOperationException("存在环");
    }
}
```

## 2. DFS 三色法

DFS 中将顶点标记为白色（未访问）、灰色（当前递归栈）、黑色（已完成）。遇到灰色邻接点即发现后向边和环；全部完成后按完成时间逆序排列即为拓扑序。递归深度接近 `V` 时可能导致 .NET 调用栈溢出，可用显式栈模拟。

## 3. 进阶：依赖调度

拓扑序本身只表达依赖先后，不表达执行时间。可在 Kahn 循环中维护 `earliest[v] = max(earliest[v], earliest[u] + duration[u])`，得到 DAG 上的关键路径长度。若任务有资源限制，需在入度为 0 的候选集中再做资源调度，不能仅依赖拓扑排序。

## 4. 常见错误

1. 把无向图送入拓扑排序；无向边会使入度逻辑失去意义。
2. 只输出入度为 0 的初始顶点，忘记在删除边后更新入度。
3. 用 `order.Count == n` 判断时忽略重复边；重复边必须分别计入入度并分别删除。
4. 发现环后仍使用部分输出作为完整计划；应将结果标记为失败。
5. DFS 版本忘记在递归返回时记录完成顺序，导致序列方向反了。

## 5. 工程示例：计算任务最早完成时间

任务调度可以把任务持续时间放在顶点上，在 Kahn 算法删除边时更新后继任务的最早开始时间。拓扑排序成功后，最大完成时间就是关键路径长度。

~~~csharp
static (int[] Order, long[] Earliest) Schedule(
    IReadOnlyList<IReadOnlyList<int>> graph,
    ReadOnlySpan<int> duration)
{
    int n = graph.Count;
    if (duration.Length != n)
        throw new ArgumentException("持续时间数量必须等于顶点数");

    int[] indegree = new int[n];
    foreach (var edges in graph)
        foreach (int v in edges) indegree[v]++;

    var queue = new Queue<int>();
    for (int i = 0; i < n; i++)
        if (indegree[i] == 0) queue.Enqueue(i);

    var order = new int[n];
    var earliest = new long[n];
    int count = 0;
    while (queue.TryDequeue(out int u))
    {
        order[count++] = u;
        earliest[u] += duration[u];
        foreach (int v in graph[u])
        {
            earliest[v] = Math.Max(earliest[v], earliest[u]);
            if (--indegree[v] == 0) queue.Enqueue(v);
        }
    }

    if (count != n) throw new InvalidOperationException("存在循环依赖");
    return (order, earliest);
}
~~~

真实调度还要处理资源数量、失败重试和取消。拓扑序只解决依赖约束，不能替代线程池、队列或分布式任务调度器。
