# 栈基础应用

栈（Stack）遵循后进先出（LIFO）：最后压入的元素最先取出。C# 的 `System.Collections.Generic.Stack<T>` 从 .NET Framework 2.0 起提供。

**版本说明：示例使用 C# 12/.NET 8（`net8.0`）。** 栈适合括号匹配、表达式解析、显式模拟递归、单调栈和撤销操作。

## 1. 复杂度与接口

`Push`、`Pop`、`Peek`、`TryPop` 和 `TryPeek` 的均摊时间复杂度为 `O(1)`；遍历全部元素为 `O(n)`，存储空间为 `O(n)`。内部数组扩容时会复制已有元素，但摊销后入栈仍为常数时间。`Stack<T>` 本身不是线程安全集合；并发场景应使用专用同步方案。

## 2. 基础用法：括号匹配

扫描字符串时，左括号入栈；右括号必须与栈顶的左括号匹配。扫描结束后栈为空，才说明所有括号都闭合。算法时间 `O(n)`，最坏空间 `O(n)`。

```csharp
public static bool IsBalanced(string text)
{
    ArgumentNullException.ThrowIfNull(text);
    var stack = new Stack<char>();

    foreach (char c in text)
    {
        if (c is '(' or '[' or '{')
        {
            stack.Push(c);
            continue;
        }

        if (c is ')' or ']' or '}')
        {
            if (!stack.TryPop(out char left) || !Matches(left, c)) return false;
        }
    }
    return stack.Count == 0;

    static bool Matches(char left, char right) =>
        (left, right) is ('(', ')') or ('[', ']') or ('{', '}');
}

Console.WriteLine(IsBalanced("{[()]}")); // True
Console.WriteLine(IsBalanced("{[(])}")); // False
```

## 3. 基础用法：后缀表达式求值

后缀表达式不需要处理运算符优先级。数字入栈；读到运算符时先弹出右操作数，再弹出左操作数，计算结果重新入栈。时间 `O(n)`，空间 `O(n)`。

```csharp
public static int EvaluatePostfix(IEnumerable<string> tokens)
{
    ArgumentNullException.ThrowIfNull(tokens);
    var values = new Stack<int>();

    foreach (string token in tokens)
    {
        if (int.TryParse(token, out int number))
        {
            values.Push(number);
            continue;
        }

        if (values.Count < 2) throw new FormatException("操作数不足");
        int right = values.Pop();
        int left = values.Pop();
        values.Push(token switch
        {
            "+" => checked(left + right),
            "-" => checked(left - right),
            "*" => checked(left * right),
            "/" when right != 0 => left / right,
            "/" => throw new DivideByZeroException(),
            _ => throw new FormatException($"未知运算符：{token}")
        });
    }

    return values.Count == 1
        ? values.Pop()
        : throw new FormatException("表达式不完整");
}

int result = EvaluatePostfix(new[] { "12", "3", "/", "4", "+" });
Console.WriteLine(result); // 8
```

## 4. 进阶：单调栈求下一个更大元素

从右向左扫描，维护值递减的下标栈。当前位置入栈前，弹出所有小于等于当前值的候选；剩余栈顶就是右侧最近的更大元素。每个下标最多入栈、出栈一次，时间 `O(n)`，空间 `O(n)`。

```csharp
public static int[] NextGreater(ReadOnlySpan<int> values)
{
    int[] answer = new int[values.Length];
    Array.Fill(answer, -1);
    var stack = new Stack<int>();

    for (int i = values.Length - 1; i >= 0; i--)
    {
        while (stack.Count > 0 && values[stack.Peek()] <= values[i]) stack.Pop();
        if (stack.Count > 0) answer[i] = values[stack.Peek()];
        stack.Push(i);
    }
    return answer;
}
```

### 4.1 显式栈模拟 DFS

递归深度可能超过调用栈容量时，可将待处理顶点压入 `Stack<int>`。若需要保持递归的邻接顺序，应按逆序入栈；否则遍历顺序会反转。

## 5. 常见错误

1. 空栈直接调用 `Pop` 或 `Peek`；优先使用 `TryPop`、`TryPeek`，或在操作前检查 `Count`。
2. 后缀表达式弹出操作数顺序颠倒，导致减法和除法结果错误。
3. 括号匹配只检查数量，不检查类型和嵌套顺序。
4. 把 `Stack<T>` 当作线程安全集合在多个线程中写入；应使用锁、线程安全集合或消息通道。
5. 单调栈只保存值、不保存下标，无法回答元素位置、距离或过期条件。
