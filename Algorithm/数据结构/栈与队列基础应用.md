# 栈与队列基础应用

栈（Stack）遵循后进先出（LIFO），队列（Queue）遵循先进先出（FIFO）。C# 标准库在 `System.Collections.Generic` 中提供 `Stack<T>` 和 `Queue<T>`，入栈/出栈、入队/出队均为均摊 `O(1)`。并发场景应使用 `ConcurrentQueue<T>`、`Channel<T>` 等专用类型，不要把普通集合当作线程安全容器。

本文件保留为合并总览；按主题拆分的详细文档见 [栈基础应用](./栈基础应用.md) 和 [队列基础应用](./队列基础应用.md)。

**示例环境：C# 12、.NET 8（`net8.0`）。** `TryDequeue` 在 .NET 6 引入；`System.Threading.Channels` 在 .NET Core 3.0 进入共享框架，适合异步生产者/消费者。

## 复杂度

普通栈和队列的入、出、查看首元素操作均为均摊 `O(1)`；遍历或复制全部元素为 `O(n)`，存储空间为 `O(n)`。`Queue<T>` 扩容时会复制元素，但摊销后单次入队仍为 `O(1)`。

## 1. 栈：括号匹配与表达式求值

括号匹配只需在遇到左括号时入栈，遇到右括号时检查栈顶类型。扫描结束时栈必须为空。该方法时间 `O(n)`，空间最坏 `O(n)`。

```csharp
public static bool IsBalanced(string text)
{
    var stack = new Stack<char>();
    foreach (char c in text)
    {
        if (c is '(' or '[' or '{') stack.Push(c);
        else if (c is ')' or ']' or '}')
        {
            if (stack.Count == 0 || !Matches(stack.Pop(), c)) return false;
        }
    }
    return stack.Count == 0;

    static bool Matches(char left, char right) =>
        (left, right) is ('(', ')') or ('[', ']') or ('{', '}');
}
```

后缀表达式（逆波兰表达式）求值同样使用栈：数字入栈，遇到运算符弹出右、左操作数，计算后再入栈。必须先弹出右操作数，否则减法和除法会颠倒。

```csharp
public static int EvaluatePostfix(IEnumerable<string> tokens)
{
    var values = new Stack<int>();
    foreach (string token in tokens)
    {
        if (int.TryParse(token, out int number)) { values.Push(number); continue; }
        if (values.Count < 2) throw new FormatException("操作数不足");
        int right = values.Pop();
        int left = values.Pop();
        values.Push(token switch
        {
            "+" => checked(left + right),
            "-" => checked(left - right),
            "*" => checked(left * right),
            "/" when right != 0 => left / right,
            "/" => throw new DivideByZeroException(),
            _ => throw new FormatException($"未知运算符：{token}")
        });
    }
    return values.Count == 1 ? values.Pop() : throw new FormatException("表达式不完整");
}
```

## 2. 栈的进阶应用：下一个更大元素

从右向左扫描数组，维护值递减的单调栈。对于当前位置，弹出小于等于当前值的元素，剩余栈顶就是右侧第一个更大值。时间 `O(n)`，空间 `O(n)`。

```csharp
public static int[] NextGreater(ReadOnlySpan<int> values)
{
    int[] answer = new int[values.Length];
    Array.Fill(answer, -1);
    var stack = new Stack<int>(); // 存下标，栈顶对应最近的候选
    for (int i = values.Length - 1; i >= 0; i--)
    {
        while (stack.Count > 0 && values[stack.Peek()] <= values[i]) stack.Pop();
        if (stack.Count > 0) answer[i] = values[stack.Peek()];
        stack.Push(i);
    }
    return answer;
}
```

## 3. 队列：任务处理与层序遍历

队列适合按到达顺序处理任务，也适合图的 BFS 和树的层序遍历。`Queue<T>.TryDequeue`（.NET 6+）可避免先检查再出队的竞态式写法：

```csharp
var jobs = new Queue<string>(new[] { "编译", "测试", "打包" });
while (jobs.TryDequeue(out string? job))
{
    Console.WriteLine($"执行：{job}");
}
```

## 4. 进阶：生产者/消费者

多线程生产者/消费者不要用 `Queue<T>` 配合手写锁，优先使用 .NET 8 的 `System.Threading.Channels`。有界通道可以提供背压，避免生产速度长期高于消费速度而耗尽内存。

```csharp
using System.Threading.Channels;

var channel = Channel.CreateBounded<string>(capacity: 100);
Task producer = Task.Run(async () =>
{
    try
    {
        for (int i = 0; i < 1_000; i++)
            await channel.Writer.WriteAsync($"job-{i}");
    }
    catch (Exception ex)
    {
        channel.Writer.TryComplete(ex);
        throw;
    }
    finally
    {
        channel.Writer.TryComplete();
    }
});
Task consumer = Task.Run(async () =>
{
    await foreach (string job in channel.Reader.ReadAllAsync())
        Process(job);
});
await Task.WhenAll(producer, consumer);

static void Process(string job) { /* 处理任务 */ }
```

## 5. 常见错误

1. 空栈调用 `Pop` 或空队列调用 `Dequeue`；使用 `TryPop`、`TryDequeue` 或先检查 `Count`。
2. 后缀表达式弹出操作数顺序错误，尤其是减法、除法。
3. 递归 DFS 深度过大导致栈溢出；可改为显式 `Stack<T>`。
4. 在多个线程间共享 `Stack<T>`/`Queue<T>`；它们不是线程安全集合。
5. 通道生产者结束后忘记 `Complete`，消费者会一直等待更多数据。
