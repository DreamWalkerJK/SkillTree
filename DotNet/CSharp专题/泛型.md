# 泛型

> 版本信息：.NET 8（C# 12）。泛型于 C# 2.0/.NET 2.0 引入；静态抽象接口成员于 C# 11/.NET 7 引入。示例目标为 `net8.0`，泛型数学代码可直接迁移到 .NET 10；.NET 11 Preview 沿用同一语法，但应按目标 SDK 验证。

泛型把类型作为参数，在编译期检查约束；运行时会针对值类型等情况进行专门化，从而通常可以避免装箱。

## 基础用法

~~~csharp
public static T Max<T>(T left, T right) where T : IComparable<T>
    => left.CompareTo(right) >= 0 ? left : right;

var numbers = new List<int> { 3, 1, 4 };
int largest = Max(numbers[0], numbers[2]);
~~~

常见约束包括 class、struct、notnull、new()、基类和接口。多个约束按顺序书写；类型参数名使用 T、TKey、TValue 等约定。

~~~csharp
public sealed class Repository<TEntity, TKey>
    where TEntity : class
    where TKey : notnull
{
    private readonly Dictionary<TKey, TEntity> _items = [];

    public void Add(TKey key, TEntity entity) => _items.Add(key, entity);
    public bool TryGet(TKey key, out TEntity? entity) =>
        _items.TryGetValue(key, out entity);
}
~~~

## 协变与逆变

接口和委托可以声明 out（协变，只读）或 in（逆变，只写）。List<T> 不变，IEnumerable<T> 协变，IComparer<T> 逆变。

~~~csharp
IEnumerable<string> names = [];
IEnumerable<object> objects = names;       // 协变
IComparer<object> comparer = Comparer<object>.Default;
IComparer<string> stringComparer = comparer; // 逆变
~~~

## 高级用法：泛型数学

C# 11 的 static abstract interface members 允许对数字类型编写统一算法。System.Numerics.INumber<T> 在 .NET 7 提供完整运算约束。

~~~csharp
using System.Numerics;

static T Sum<T>(ReadOnlySpan<T> values) where T : INumber<T>
{
    T total = T.Zero;
    foreach (T value in values)
        total += value;
    return total;
}

int i = Sum<int>([1, 2, 3]);
decimal d = Sum<decimal>([1.5m, 2.5m]);
~~~

泛型静态字段按闭合类型分别存储，可用于高效类型级缓存。JIT 会对值类型和部分引用类型进行专门化；过度泛型化会增加代码体积，公共库应保持约束清晰。

## 性能与设计建议

- 优先使用泛型集合而非非泛型 ICollection，避免装箱。
- 约束表达真实需求，不要为了调用方便滥用 new()。
- 需要类型元数据时可在泛型静态构造函数中一次初始化。
- AOT 场景避免未受约束的反射和动态代码，必要时使用源生成器。
