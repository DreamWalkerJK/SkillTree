# 反射

> 版本信息：.NET 8（C# 12）。System.Reflection 自 .NET 1.0 可用；MetadataLoadContext 于 .NET Core 3.0 引入；NativeAOT/.NET 8 对动态反射有裁剪限制。示例目标为 `net8.0`，可迁移到 .NET 10；.NET 11 Preview 的行为需按目标 SDK 验证。

反射在运行时读取程序集、类型、成员和自定义属性，并可创建对象或调用方法。它适用于插件、序列化、测试和框架基础设施，不应替代普通业务调用。

## 基础用法

~~~csharp
using System;
using System.Collections.Generic;

Type type = typeof(DateTime);
Console.WriteLine(type.FullName);

foreach (System.Reflection.PropertyInfo property in type.GetProperties())
    Console.WriteLine(property.Name + ": " + property.PropertyType.Name);

object? value = Activator.CreateInstance(typeof(List<int>));
~~~

通过 BindingFlags 精确筛选成员，调用前检查参数和可见性：

~~~csharp
using System;
using System.Reflection;

var flags = System.Reflection.BindingFlags.Instance |
            System.Reflection.BindingFlags.Public;
System.Reflection.MethodInfo? method =
    typeof(string).GetMethod("GetHashCode", flags,
        binder: null, types: Type.EmptyTypes, modifiers: null);
if (method is not null)
{
    int hash = (int)method.Invoke("abc", null)!;
}
~~~

## 自定义属性

~~~csharp
using System;
using System.Linq;

[AttributeUsage(AttributeTargets.Class, Inherited = false)]
public sealed class PluginAttribute(string name) : Attribute
{
    public string Name { get; } = name;
}

[Plugin("orders")]
public sealed class OrderPlugin { }

PluginAttribute? metadata = typeof(OrderPlugin)
    .GetCustomAttributes<PluginAttribute>(inherit: false)
    .SingleOrDefault();
~~~

## 高级用法

MetadataLoadContext（.NET Core 3.0）可在隔离的只读上下文检查未知程序集，避免执行其静态构造函数。插件系统应使用 AssemblyLoadContext，卸载时确保没有对象、线程或事件引用留在默认上下文。

~~~csharp
using System.Reflection;
using System.Runtime.Loader;

var loadContext = new AssemblyLoadContext("plugin", isCollectible: true);
Assembly assembly = loadContext.LoadFromAssemblyPath(pluginPath);
Type[] exported = assembly.GetExportedTypes();
loadContext.Unload();
~~~

反射调用 MethodInfo.Invoke 会进行参数数组封装和异常包装（TargetInvocationException）。热点路径可将 MethodInfo 创建为委托并缓存：

~~~csharp
using System;
using System.Reflection;

MethodInfo method = typeof(Calculator).GetMethod(nameof(Calculator.Add))!;
var add = (Func<Calculator, int, int, int>)
    method.CreateDelegate(typeof(Func<Calculator, int, int, int>));
~~~

在 NativeAOT 或启用 Trim 的发布中，反射访问的类型必须通过 DynamicallyAccessedMembers、DynamicDependency 或源生成器显式保留。优先使用编译期生成代码，只有真正需要可扩展性时才保留反射。

示例中的 `Calculator` 需提供与 `Func<Calculator,int,int,int>` 匹配的实例 `Add(int,int)` 方法；生产代码应检查方法签名，避免无效强制转换。

## 工程示例：按约定发现处理器

插件系统可以用 Attribute 标记处理器，再在启动阶段扫描一次程序集并建立字典。请求路径只访问已经缓存的委托，避免每次请求重复调用 `GetTypes` 和 `GetMethod`。

~~~csharp
[AttributeUsage(AttributeTargets.Class, AllowMultiple = false)]
public sealed class HandlerAttribute(string name) : Attribute
{
    public string Name { get; } = name;
}

public interface IHandler
{
    Task HandleAsync(string input, CancellationToken token);
}

static IReadOnlyDictionary<string, Func<IHandler>> Discover(Assembly assembly)
    => assembly.GetTypes()
        .Where(t => !t.IsAbstract && typeof(IHandler).IsAssignableFrom(t))
        .Select(t => (Type: t, Attribute: t.GetCustomAttribute<HandlerAttribute>()))
        .Where(x => x.Attribute is not null)
        .ToDictionary(x => x.Attribute!.Name,
            x => () => (IHandler)Activator.CreateInstance(x.Type)!);
~~~

扫描结果应在启动阶段验证：名称不能重复，类型必须有可用构造函数，方法签名必须符合契约。插件来自不可信来源时，反射无法替代隔离，必须使用进程或容器边界。
