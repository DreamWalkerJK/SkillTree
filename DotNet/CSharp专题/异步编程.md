# 异步编程

> 版本信息：.NET 8（C# 12）。核心语法于 C# 5.0、.NET Framework 4.5 引入；示例目标为 `net8.0`，可迁移到 .NET 10；.NET 11 Preview 需锁定具体 SDK 并单独验证。

异步方法在等待网络、磁盘、数据库等 I/O 时释放当前线程。它改善吞吐和响应性，但不会让 CPU 计算本身变快。

## 基础用法

异步方法返回 Task、Task<T> 或 ValueTask<T>。除事件处理程序外，不要使用 async void；调用方应一路 await 到应用程序入口。

~~~csharp
// TargetFramework: net8.0
using System.Net.Http;

static async Task<string> GetTextAsync(
    HttpClient client, Uri uri, CancellationToken cancellationToken)
{
    using HttpResponseMessage response =
        await client.GetAsync(uri, cancellationToken);
    response.EnsureSuccessStatusCode();
    return await response.Content.ReadAsStringAsync(cancellationToken);
}

using var client = new HttpClient();
using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(10));
string text = await GetTextAsync(
    client, new Uri("https://example.com"), cts.Token);
Console.WriteLine("长度：" + text.Length);
~~~

多个独立操作可以并发发起，再用 Task.WhenAll 汇总：

~~~csharp
Task<string> a = GetTextAsync(client, new Uri("https://example.com/a"), cts.Token);
Task<string> b = GetTextAsync(client, new Uri("https://example.com/b"), cts.Token);
string[] result = await Task.WhenAll(a, b);
~~~

## 取消、超时与异常

CancellationToken 是协作式取消。Task.WaitAsync（.NET 6）可给已有任务增加等待超时，但不会强制终止底层操作；底层 API 仍应接收令牌。

~~~csharp
static async Task<T> WithTimeoutAsync<T>(
    Task<T> operation, TimeSpan timeout, CancellationToken cancellationToken)
{
    using var timeoutSource =
        CancellationTokenSource.CreateLinkedTokenSource(cancellationToken);
    timeoutSource.CancelAfter(timeout);
    return await operation.WaitAsync(timeoutSource.Token);
}
~~~

WhenAll 失败时要记录每个任务的 Exception；区分 OperationCanceledException 与真正的业务故障。不要使用 Result、Wait 或 Thread.Sleep 阻塞异步链，它们会降低线程池利用率，旧版同步上下文中还可能死锁。

## 高级用法

ValueTask<T>（.NET Core 2.1）适合大多数调用同步完成的热点 API。除非明确知道底层实现支持多次等待，否则不要重复消费同一个 ValueTask；需要缓存或多次等待时返回 Task<T>。

~~~csharp
public sealed class ValueCache
{
    private readonly Dictionary<int, string> _cache = [];

    public ValueTask<string> GetAsync(int id)
    {
        if (_cache.TryGetValue(id, out string? value))
            return ValueTask.FromResult(value);
        return LoadAsync(id);
    }

    private async ValueTask<string> LoadAsync(int id)
    {
        await Task.Delay(1);
        string value = "user-" + id;
        _cache[id] = value;
        return value;
    }
}
~~~

IAsyncDisposable（.NET Core 3.0）对象使用 await using。ConfigureAwait(false) 适合通用库，避免恢复到不存在的同步上下文；UI 应用则保留默认行为以回到 UI 线程。高并发访问共享资源时，用 SemaphoreSlim 或 Parallel.ForEachAsync（.NET 6）限制并行度。

~~~csharp
await using FileStream stream = File.OpenWrite("output.bin");
await stream.WriteAsync(data, cancellationToken);
~~~

## 设计要点

- 每个公共异步 API 都传播取消令牌并定义超时策略。
- HttpClient 在 ASP.NET Core 中通过 IHttpClientFactory 管理生命周期。
- 重试只用于幂等操作，并采用指数退避；不要重试取消和参数错误。
- 记录操作耗时、取消和异常，避免在日志中泄漏敏感数据。
