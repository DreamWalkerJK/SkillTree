# 不安全代码

> 版本信息：指针语法自 C# 1.0/.NET 1.0；fixed 语句、stackalloc 同期可用；Span<T> 的安全切片 API 于 C# 7.2/.NET Core 2.1 引入；.NET 8 NativeAOT 对不安全和运行时生成有额外限制。示例目标 net8.0。

不安全代码允许使用指针、固定托管对象和本机内存。它能实现底层互操作和低层性能优化，但会绕过部分运行时检查，错误可能造成越界、数据损坏或进程崩溃。项目需在 csproj 中设置 AllowUnsafeBlocks=true。

## 基础指针操作

~~~csharp
// <AllowUnsafeBlocks>true</AllowUnsafeBlocks>
static unsafe int Sum(int* values, int length)
{
    int total = 0;
    for (int i = 0; i < length; i++)
        total += values[i];
    return total;
}
~~~

托管数组必须在 fixed 块中固定，防止 GC 移动对象：

~~~csharp
static unsafe int First(int[] values)
{
    fixed (int* p = values)
        return p[0];
}
~~~

fixed 的作用域应尽可能短；不要把指针保存到块外。

## stackalloc 与 Span

C# 7.2 以后推荐把 stackalloc 结果包装为 Span<T>，既高效又保留长度检查：

~~~csharp
static int ParseHex(ReadOnlySpan<char> text)
{
    if ((text.Length & 1) != 0)
        throw new FormatException("十六进制文本必须包含偶数个字符");
    if (text.Length > 1024)
        throw new ArgumentOutOfRangeException(nameof(text), "输入过大");
    Span<byte> bytes = stackalloc byte[text.Length / 2];
    for (int i = 0; i < bytes.Length; i++)
    {
        int high = HexValue(text[i * 2]);
        int low = HexValue(text[i * 2 + 1]);
        if (high < 0 || low < 0)
            throw new FormatException("无效的十六进制文本");
        bytes[i] = (byte)((high << 4) | low);
    }
    return bytes.Length;

    static int HexValue(char c) => c switch
    {
        >= '0' and <= '9' => c - '0',
        >= 'A' and <= 'F' => c - 'A' + 10,
        >= 'a' and <= 'f' => c - 'a' + 10,
        _ => -1
    };
}
~~~

stackalloc 大小必须受控，不能把用户输入长度直接分配到栈上；大缓冲区改用 ArrayPool<T> 或租赁内存。

## 高级用法：本机内存

~~~csharp
using System.Runtime.InteropServices;

unsafe
{
    nint pointer = Marshal.AllocHGlobal(1024);
    try
    {
        Span<byte> buffer = new((void*)pointer, 1024);
        buffer.Clear();
    }
    finally
    {
        Marshal.FreeHGlobal(pointer);
    }
}
~~~

更推荐 SafeHandle 管理资源，确保异常路径释放。不要混用 AllocHGlobal 与 free 等不匹配的释放函数。

## 安全与验证

- 任何指针算术都要验证长度、对齐和整数溢出。
- 不安全代码集中在小型适配层，提供安全托管 API。
- 发布前启用 AddressSanitizer（支持的工具链）或本机调试器检查越界。
- NativeAOT、WASM、受限沙箱可能不允许特定本机调用；提供纯托管回退路径。
