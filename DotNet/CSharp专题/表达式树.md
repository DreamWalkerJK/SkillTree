# 表达式树

> 版本信息：.NET 10（C# 14）。System.Linq.Expressions 随 C# 3.0/.NET 3.5 引入；`Expression<TDelegate>` 可把 Lambda 保存为可检查的语法树；现代 .NET 持续优化解释器和编译性能。示例目标为 `net10.0`。

表达式树把 Lambda 表示为节点图，而不是立即执行的委托。ORM、规则引擎和查询提供程序可以读取节点并翻译为 SQL 或其他语言。

## 基础用法

~~~csharp
using System.Linq.Expressions;

Expression<Func<int, bool>> positive = x => x > 0;
Console.WriteLine(positive.Body.NodeType);
Func<int, bool> predicate = positive.Compile();
bool ok = predicate(3);
~~~

构建动态条件：

~~~csharp
ParameterExpression p = Expression.Parameter(typeof(Order), "order");
MemberExpression total = Expression.Property(p, nameof(Order.Total));
BinaryExpression body = Expression.GreaterThan(
    total, Expression.Constant(100m));
Expression<Func<Order, bool>> rule =
    Expression.Lambda<Func<Order, bool>>(body, p);
~~~

## 组合与参数替换

直接使用 AndAlso 组合两个表达式时参数实例必须一致。可使用 ExpressionVisitor 替换参数：

~~~csharp
sealed class ReplaceVisitor(ParameterExpression from,
                            ParameterExpression to) : ExpressionVisitor
{
    protected override Expression VisitParameter(ParameterExpression node) =>
        node == from ? to : base.VisitParameter(node);
}

static Expression<Func<T, bool>> And<T>(
    Expression<Func<T, bool>> left,
    Expression<Func<T, bool>> right)
{
    var parameter = Expression.Parameter(typeof(T), "x");
    var l = new ReplaceVisitor(left.Parameters[0], parameter).Visit(left.Body)!;
    var r = new ReplaceVisitor(right.Parameters[0], parameter).Visit(right.Body)!;
    return Expression.Lambda<Func<T, bool>>(
        Expression.AndAlso(l, r), parameter);
}
~~~

## 高级用法与限制

`IQueryable<T>` 将表达式交给提供程序；并非所有 .NET 方法都有对应翻译。`AsEnumerable` 本身不执行或缓存查询，它使后续 LINQ 运算符按 `IEnumerable<T>` 的方式执行。正常 JIT 环境中 `Compile()` 可生成动态方法；Native AOT 不支持动态代码生成，表达式树改用解释执行。需要明确选择解释器时可调用 `Compile(preferInterpretation: true)`，并用实际工作负载比较性能。

表达式树不支持所有新 C# 语法（例如 async Lambda、模式匹配的部分形式）。需要自定义 DSL 时定义节点白名单，避免执行任意方法造成安全问题，并缓存已编译委托以减少开销。

## 工程示例：构造可组合过滤器

查询页面通常需要把多个可选条件组合成一个表达式。参数必须统一替换，否则把两个 Lambda 直接用 `AndAlso` 拼接会出现不同参数对象，最终无法编译。

~~~csharp
using System.Linq.Expressions;

ExpressionSample.Run();

public static class ExpressionSample
{
    public sealed record Product(int Id, string Name, decimal Price, bool Enabled);

    public static Expression<Func<Product, bool>> And(
        Expression<Func<Product, bool>> left,
        Expression<Func<Product, bool>> right)
    {
        var parameter = Expression.Parameter(typeof(Product), "p");
        var leftBody = new ReplaceParameter(left.Parameters[0], parameter).Visit(left.Body)!;
        var rightBody = new ReplaceParameter(right.Parameters[0], parameter).Visit(right.Body)!;
        return Expression.Lambda<Func<Product, bool>>(
            Expression.AndAlso(leftBody, rightBody), parameter);
    }

    private sealed class ReplaceParameter(ParameterExpression from, ParameterExpression to)
        : ExpressionVisitor
    {
        protected override Expression VisitParameter(ParameterExpression node)
            => node == from ? to : base.VisitParameter(node);
    }

    public static void Run()
    {
        var filter = And(p => p.Enabled, p => p.Price <= 100m);
        var products = new List<Product>();
        List<Product> result = products.AsQueryable().Where(filter).ToList();
        Console.WriteLine(result.Count);
    }
}

~~~

`IQueryable<T>` 提供程序可能无法翻译自定义方法、反射调用或复杂条件。公共查询组件应先定义可翻译的表达式，再在内存阶段执行格式化和业务展示逻辑；不要把 `Compile()` 后的委托传给数据库查询。
