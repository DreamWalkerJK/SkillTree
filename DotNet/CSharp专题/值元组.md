# 值元组（ValueTuple）

> 版本信息：.NET 8（C# 12）。System.ValueTuple 和元组语法于 C# 7.0/.NET Framework 4.7、.NET Core 2.0 引入；C# 7.2 支持 in 参数和更多按引用传递场景。示例目标为 `net8.0`，可迁移到 .NET 10；.NET 11 Preview 需按目标 SDK 验证。

ValueTuple 是值类型，适合在方法内部或紧邻调用方的位置返回多个值。它与旧式 System.Tuple 引用类型不同，不应把它误当作稳定的公共数据契约。

## 基础用法

~~~csharp
static (int Min, int Max) FindRange(IEnumerable<int> source)
{
    int min = int.MaxValue, max = int.MinValue;
    foreach (int value in source)
    {
        min = Math.Min(min, value);
        max = Math.Max(max, value);
    }
    return (min, max);
}

(int min, int max) = FindRange([4, 1, 9]);
Console.WriteLine(min + ".." + max);
~~~

元素可以有名称，也可以使用 Item1、Item2 访问。名称只是编译期提示，元数据中仍以 ItemN 字段为主。

~~~csharp
var point = (X: 3, Y: 4);
Console.WriteLine(point.X + point.Y);
~~~

## 解构与忽略

元组支持解构。使用下划线忽略不需要的元素；同一作用域内的下划线变量不会被重复赋值。

~~~csharp
(string host, int port, _) = ParseEndpoint("db:5432");
static (string, int, bool) ParseEndpoint(string value)
{
    string[] parts = value.Split(':', 2);
    return (parts[0], int.Parse(parts[1]), true);
}
~~~

## 高级用法

ValueTuple 实现结构相等和哈希，可作为 Dictionary 键。对大量临时元组，避免把大型结构复制到堆上；必要时使用 in 参数或自定义 readonly struct。

~~~csharp
var cache = new Dictionary<(string Region, int Id), decimal>
{
    [("cn", 1)] = 12.5m
};
if (cache.TryGetValue(("cn", 1), out decimal price))
    Console.WriteLine(price);
~~~

异步方法可以返回元组，但只返回轻量结果：

~~~csharp
static async Task<(bool Found, string? Value)> TryReadAsync(
    Stream stream, CancellationToken token)
{
    await Task.Yield();
    return (true, "ok");
}
~~~

元组转换要求元素数量、类型和名称兼容；名称不参与类型身份。跨程序集、需要版本演进或要挂载验证逻辑时，定义 record 或 class 更清晰。

## 与 Span 和模式匹配配合

元组模式可用于同时判断多个值：

~~~csharp
static string Describe(int status, bool cached) => (status, cached) switch
{
    (200, true) => "缓存命中",
    (200, false) => "新数据",
    (404, _) => "不存在",
    _ => "其他"
};
~~~

## 注意事项

- ValueTuple 是可变字段；公开 API 返回后不要让调用方依赖字段可变性。
- 不要把敏感数据放进会被日志或调试器展开的元组。
- 对高频分配场景，确认真正的瓶颈后再选择 ValueTuple；基准测试比直觉可靠。
