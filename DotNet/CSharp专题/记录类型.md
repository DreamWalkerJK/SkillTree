# 记录类型（Records）

> 版本信息：.NET 10（C# 14）。引用类型记录 `record` 于 C# 9 引入，显式 `record class` 写法和 `record struct` 于 C# 10 引入；`init` 访问器于 C# 9，`required` 成员于 C# 11；C# 12 引入普通 class/struct 的主构造函数。示例目标为 `net10.0`。

记录类型面向数据模型，编译器提供值相等、格式化和非破坏性复制支持，位置记录还会生成解构方法。`record class` 是引用类型，位置参数默认生成 `init` 属性，但记录并不保证深度不可变；`record struct` 是值类型。

## 基础用法

~~~csharp
public record User(int Id, string Name);

User first = new(1, "Ada");
User same = new(1, "Ada");
Console.WriteLine(first == same); // true：值相等

User renamed = first with { Name = "Grace" };
Console.WriteLine(first.Name);   // Ada
Console.WriteLine(renamed.Name); // Grace
~~~

编译器生成 EqualityContract、Equals、GetHashCode、ToString 和 Deconstruct。record 的相等比较包含运行时类型，派生 record 不会与基类 record 自动相等。

## 可变性与 record struct

~~~csharp
public readonly record struct Money(decimal Amount, string Currency);

Money price = new(10m, "CNY");
Console.WriteLine(price.Amount);

public record Order
{
    public required int Id { get; init; }
    public string Status { get; init; } = "New";
}
~~~

readonly record struct（C# 10）避免值类型字段被意外修改。record struct 默认可变，若作为字典键应优先使用 readonly 版本。

## 高级用法：继承与验证

~~~csharp
public record Event(DateTimeOffset OccurredAt);
public sealed record UserRegistered : Event
{
    public int UserId { get; }

    public UserRegistered(DateTimeOffset occurredAt, int userId)
        : base(occurredAt)
    {
        if (userId <= 0) throw new ArgumentOutOfRangeException(nameof(userId));
        UserId = userId;
    }
}
~~~

上例展示了概念；更常见的写法是在工厂方法中验证，避免复杂构造器语法：

~~~csharp
public record Product(string Sku, decimal Price)
{
    public static Product Create(string sku, decimal price)
    {
        if (string.IsNullOrWhiteSpace(sku) || price < 0)
            throw new ArgumentOutOfRangeException();
        return new Product(sku, price);
    }
}
~~~

with 表达式只复制浅层成员；嵌套 List 或数组仍共享引用，需要手动实现深拷贝。记录适合消息、DTO、值对象，不适合承载需要身份跟踪和大量行为的实体。

## 序列化与版本演进

System.Text.Json 可直接序列化 record。公共消息应明确字段兼容策略，新增可选属性并保留旧属性读取逻辑：

~~~csharp
using System.Text.Json;

string json = JsonSerializer.Serialize(first);
User? copy = JsonSerializer.Deserialize<User>(json);
~~~

## 设计建议

- 用 record 表达“数据相等”，用 class 表达“对象身份”。
- 把校验集中在工厂或构造器；不要依赖 with 后仍满足原不变量。
- 公开 API 中稳定的 DTO 可使用 record class，避免暴露可变集合。

## 工程示例：不可变命令与领域校验

记录类型的值相等适合表达命令、事件和查询结果。构造时应完成必要校验，避免通过 `with` 生成不符合业务约束的新对象。

~~~csharp
public sealed record CreateInvoiceCommand
{
    public required string CustomerId { get; init; }
    public required decimal Amount { get; init; }

    public CreateInvoiceCommand Normalize()
    {
        if (string.IsNullOrWhiteSpace(CustomerId))
            throw new ArgumentException("CustomerId 不能为空");
        if (Amount <= 0)
            throw new ArgumentOutOfRangeException(nameof(Amount));
        return this with { CustomerId = CustomerId.Trim() };
    }
}
~~~

编译器生成的记录相等比较会比较实例字段，包括自动属性的支持字段，并调用对应类型的默认相等比较器。数组、`List<T>` 等集合不会因此自动按元素比较；`with` 也只做浅复制。不可变集合能限制修改，但不能一概认为它会提供逐元素相等；需要按元素判断内容时，应明确使用 `SequenceEqual`，或为该成员设计带有相等比较和哈希规则的值类型。
